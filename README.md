# PDF Password Cracking Lab 🔐

## 📌 About the Project

This project demonstrates password recovery for three password-protected PDF files as part of cybersecurity and ethical hacking lab tasks. The objective was to understand how password cracking works, how password hashes can be extracted from encrypted PDFs, and how different tools can be used to recover passwords in an authorized lab environment.

## 🎯 Objectives

- Understand the basics of password cracking and PDF password protection.
- Extract password hashes from locked PDF files.
- Use John the Ripper and Johnny GUI for password recovery.
- Explore Networkwalks Hash Calculator and Password Cracker tools.
- Verify the recovered passwords by opening the protected PDF files.

## 🛠️ Tools Used

- **John the Ripper (JTR):** Password recovery tool.
- **Johnny GUI:** Graphical interface for John the Ripper.
- **Networkwalks Hash Calculator:** Extracts password hashes from protected PDFs.
- **Networkwalks Password Cracker:** Attempts to recover passwords from extracted hashes.
- **Online PDF Hash Extractor:** Used for extracting PDF password hashes.
- **Windows / Kali Linux:** Lab environments.

## ⚙️ Methodology

### 1. PDF Password Hash Extraction

- Selected a password-protected PDF file.
- Uploaded the file to a PDF hash extraction tool.
- Extracted and copied the hash value for password recovery.

### 2. Password Recovery Using John the Ripper

- Saved the extracted hash in a text file.
- Opened Johnny and configured the John the Ripper executable.
- Loaded the hash file and started the password recovery process.
- Waited for the tool to identify the password.

### 3. Password Recovery Using Networkwalks Tools

- Uploaded the protected PDF to the Networkwalks Hash Calculator.
- Copied the extracted hash.
- Pasted the hash into the Networkwalks Password Cracker.
- Started the cracking process and checked the result.

### 4. Password Verification

- Opened the protected PDF using the recovered password.
- Verified that the file could be accessed successfully.

### 5. Testing Multiple PDFs

The same lab process was performed on three locked PDF files to practise hash extraction, password recovery, and password verification.

## 📊 Results

- Successfully practised extracting PDF password hashes.
- Used John the Ripper and Johnny GUI for password recovery.
- Explored browser-based password recovery tools from Networkwalks.
- Verified recovered passwords by opening the protected PDF files.

## 📚 Key Learnings

- Difference between encryption and hashing.
- How password hashes are extracted from protected PDF files.
- Basic use of John the Ripper and Johnny GUI.
- How browser-based password recovery tools work.
- Importance of using strong, unique passwords to improve security.
